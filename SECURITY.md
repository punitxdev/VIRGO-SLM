# Security Policy

## Supported Versions

Security updates are actively applied to the following versions of Virgo:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of our codebase seriously. If you discover a security vulnerability, potential safety concern, or malicious output vector within Virgo SLM, please follow these steps:

1. **Do Not Open a Public Issue**: Please refrain from submitting vulnerability details via public GitHub issues or discussions.
2. **Contact Maintainers Directly**: Send a detailed report to the maintainer:
   - **Maintainer**: Punit Kumar Kashyap
   - **Institution**: Indian Institute of Technology Dharwad
3. **Include Details**:
   - Description of the vulnerability or security flaw
   - Steps to reproduce the issue
   - Potential impact and suggested mitigations (if available)

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Status Update & Assessment**: Within 5 business days.
- **Fix Release**: As soon as possible depending on severity.

Thank you for helping keep the open-source AI ecosystem safe!
